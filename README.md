# CedarBite

CedarBite is a student project exploring a simpler way for Cedar College students to order canteen food.

## Current features

- Quick Order and Scheduled Order menu views
- Sample menu items
- Add items to a bucket
- Change item quantities and remove items
- View the bucket subtotal

## Current scope

The current version is a front-end interface using sample menu data. It does not yet connect to a canteen database, process payments, or submit real orders. Menu prices and availability should be checked with the canteen before being treated as official.
